═══════════════════════════════════════════════════════════════════════════
  📊 PROBLEMAS Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════

❌ "No puedo acceder a http://localhost:5173"

   Solución:
   1. docker ps
   2. Ver si hay contenedores corriendo
   3. docker-compose logs frontend
   4. Si hay error, reiniciar:
      docker-compose down
      docker-compose up -d

---

❌ "La página no muestra nada / está en blanco"

   Esto es NORMAL en la primera sesión 😊
   
   Razón: El frontend React está listo, pero aún
   no tiene componentes de UI implementados.
   
   ✅ Lo que SÍ está funcionando:
   • Backend corriendo
   • APIs disponibles
   • Base de datos conectada
   • Todo listo para desarrollo
   
   En próxima sesión implementaremos:
   • Login page
   • Dashboard
   • Módulos completos

---

❌ "API dice CORS error"

   Solución:
   1. Verificar que FRONTEND_URL en .env es correcto
   2. backend/src/main.ts tiene CORS configurado
   3. Reiniciar backend:
      docker-compose restart backend

---

❌ "Base de datos no conecta"

   Solución:
   1. docker-compose logs postgres
   2. Esperar 30 segundos (PostgreSQL tarda)
   3. docker-compose restart postgres

---

❌ "Port 5173 o 3000 ya está en uso"

   Solución:
   1. docker-compose down
   2. docker ps (para verificar que se detuvo)
   3. docker-compose up -d
